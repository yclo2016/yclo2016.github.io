# AI Research Notes

YC 的個人部落格：研究筆記與手把手教學 → <https://yclo2016.github.io>

使用 [Jekyll](https://jekyllrb.com/) 與 [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) 主題，合併到 `main` 後由 GitHub Actions 自動部署到 GitHub Pages。

## 新增文章

在 `_posts/` 新增 `YYYY-MM-DD-英文-slug.md`，寫作規則見 [`CLAUDE.md`](CLAUDE.md)。

## 本機預覽（選用）

```bash
bundle install
bash tools/run.sh   # 開啟 http://127.0.0.1:4000
```
